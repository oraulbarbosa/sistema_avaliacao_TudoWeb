# ⭐ Sistema de Avaliação

- O programa classifica o tipo de consumo com base no tipo do imóvel e metros cúbicos (m³)
- O programa classifica como foi o atendimendo do usuário e armazena a contagem dos votos.

## 📋 Descrição

Este programa em Python ajuda você a:

- Coletar o **nome** e a **idade** de cada cliente
- Registrar a **avaliação do atendimento** (Excelente, Bom ou Ruim)
- Contabilizar os votos em cada categoria
- Validar a entrada, rejeitando valores fora de 1, 2 ou 3
- Exibir ao final a quantidade de votos **EXCELENTES** e **RUINS**

## ⚡ Funcionalidades

- Solicita o **nome do cliente**
- Solicita a **idade do cliente**
- Solicita a **avaliação do atendimento** (1, 2 ou 3)
- Repete a pesquisa **10 vezes** (uma para cada cliente)
- Classifica a avaliação em: ⭐ **EXCELENTE**, 👍 **BOM** ou 👎 **RUIM**
- Contabiliza os votos em cada categoria
- Valida a entrada, rejeitando valores fora de 1, 2 ou 3
- Exibe ao final a **quantidade de votos** em cada categoria

## 🚀 Como Executar

**Pré-requisitos**
- Python 3.14 instalado

**Passo a passo**

1. Clone o repositório:
    ```bash
    git clone https://github.com/oraulbarbosa/sistema_avaliacao_TudoWeb.git
    ```
2. Acesse a pasta do projeto:
   ```bash
   cd sistema_consumo
   ```
3. Execute o programa:
   ```bash
   python app.py
   ```
4. Digite o nome do cliente e o valor da compra quando solicitado.

## 📊 Regras de Pesquisa

| Opção | Avaliação | Significado |
|-------|-----------|-------------|
| 1 | ⭐ EXCELENTE | Atendimento excelente |
| 2 | 👍 BOM | Atendimento bom |
| 3 | 👎 RUIM | Atendimento ruim |

> **Observação:** O programa repete a pesquisa **10 vezes** (uma para cada cliente).
